# WaypointCargo

Full-stack application with React frontend and Node.js backend.

## Quick Start

### Backend Setup

```bash
cd backend
npm install
```

Add `.env` file in the backend root folder, then run:

```bash
npx prisma generate
npm run dev
```

Backend runs on `http://localhost:8000`

### Frontend Setup

```bash
cd web
npm install
```

Add `.env` file in the web root folder, then run:

```bash
npm run dev
```

Frontend runs on `http://localhost:5173`
